### 🛠️ What I do as an FDE

- **Embed with the customer.** I sit with the people who do the work, map their real workflow, and find the one metric that matters: leads, hours saved, response time.
- **Ship working systems fast.** I build end-to-end on the client's real data and tools (WordPress, HubSpot, Search Console, WhatsApp, Telegram) instead of adding yet another dashboard.
- **Deploy safely.** Human approval before anything external, deterministic fallbacks for every model call, budget caps, monitoring and runbooks.
- **Close the loop.** I turn what I learn on each deployment into reusable tools and products.

My process is written up in the 📘 **[FDE Deployment Playbook](https://github.com/fde-nazmul/fde-deployment-playbook)**.
